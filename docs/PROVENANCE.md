# Provenance of version 0.3.0

Prepared on 10 September 2026 from the corrected manuscript and its independently
implemented numerical supplement. The original uploaded article contained no
source code or raw numerical data. These programs therefore do not recover or
certify any unavailable original implementation.

ChatGPT (OpenAI) assisted with mathematical analysis, drafting, code preparation
and execution of the numerical checks during the revision. All numerical values
used in the revised illustrations were generated by the supplied Python
programs. No external human review or author validation is inferred from a
successful automated test.

Version 0.3.0 separates the software project from Overleaf, adds explicit output
directories, checks input validity, compares regenerated data with reference
files, and supplies a GitHub workflow. It does not add a new regularity claim.

The eight references in `references.bib` were checked during the manuscript
audit. The older bibliography's full audit is retained in the Overleaf archive.
No claim of exhaustive literature coverage or mathematical priority is made.
